# meeting-followup (프로젝트 A)

> **현재 구현 금지 (후순위).** local-ledger 완료 후 별도 계획·승인을 거쳐 시작한다.

## 개념
회의 메모를 붙여 넣으면 요약, 액션 아이템, 클라이언트용 후속 메일 초안(존댓말)을 생성한다.

## MVP
1. 붙여넣기 입력 + 민감정보 마스킹(전화·이메일 패턴, 브라우저에서 처리)
2. 요약 3~5줄 + 액션 아이템(담당·기한이 없으면 "미정")
3. 후속 메일 초안(톤 2종: 정중, 간결)
4. 복사 / 메일 앱 열기
5. 일정 재조율 요청 문구 템플릿(비AI)

## 제외
계정 연동, 녹음·음성→텍스트, 로그인, 서버 저장, 팀 공유, 캘린더 자동 등록

## 기술
- Nitro 서버 라우트를 LLM 프록시로 사용
- 출력은 JSON 스키마로 고정
- 요청 본문 무로그·무저장
- 일일 호출 제한, LLM 제공사 쪽 월 사용 상한 설정

## 프라이버시 한계
AI 호출로 텍스트가 제공사에 전달되므로 "브라우저 안에서만 처리"는 불가능하다. 전송 전 고지와 마스킹으로 대응한다.
